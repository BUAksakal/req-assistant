# req-assistant

[![CI](https://github.com/BUAksakal/req-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/BUAksakal/req-assistant/actions/workflows/ci.yml)

Extracts requirements from automotive PDF specifications and checks them for conflicts, ambiguity and regulatory compliance.

## Setup

```bash
uv sync
uv run pytest
```
